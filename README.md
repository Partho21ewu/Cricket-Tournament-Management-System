# Cricket Tournament Management System

## Overview

The Cricket Tournament Management System is a web-based application developed to efficiently manage cricket tournament data, including teams, players, schedules, stadiums, and rankings. The system provides separate interfaces for administrators and users, enabling streamlined tournament administration and information access.

## Features

### Admin Module

* Admin Authentication
* Add New Players
* Update Player Statistics
* Delete Player Records
* Add Match Schedules
* Manage Stadium Information
* View Team Rankings

### User Module

* User Login
* Search Players
* View Match Schedules
* View Team Rankings
* Access Cricket Board Information
* Browse Stadium Details

## Database Design

The system uses a relational database containing entities such as:

* Players
* Teams
* Schedules
* Stadiums
* Cricket Boards
* Admin Accounts
* User Accounts

Advanced database concepts implemented:

* Stored Procedures
* SQL Triggers
* Relational Constraints
* CRUD Operations

## Installation

1. Install XAMPP.
2. Place the project folder inside the htdocs directory.
3. Import the provided SQL file into MySQL.
4. Start Apache and MySQL services.
5. Open the application through localhost.
